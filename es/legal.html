Para qué es este sitio

Este sitio es mi portfolio profesional. Existe para mostrar mi trabajo y mi experiencia a recruiters, equipos de selección y personas que estén pensando en trabajar conmigo. No es un producto, un servicio ni una tienda.

De quién es el contenido

Todo el contenido de este sitio, incluidos textos, proyectos, diseños, capturas, ilustraciones, videos, maquetación y código, pertenece a David Hoyos o a las empresas para las que se hizo el trabajo, y está protegido por las leyes de derecho de autor y de propiedad intelectual.

Podés ver este sitio para evaluar mi trabajo profesional. Cualquier otro uso requiere mi permiso previo por escrito. En particular, no podés:

  • reproducir, copiar o descargar el contenido para reutilizarlo, en todo o en parte;
  • publicarlo, distribuirlo, compartirlo o mostrarlo en otro sitio, plataforma o documento;
  • modificarlo o crear obras derivadas a partir de él;
  • usarlo con fines comerciales;
  • recopilarlo de forma automática (scraping), ni usarlo para entrenar, ajustar o evaluar modelos de IA o de machine learning, ni para armar datasets;
  • presentar este trabajo como propio o como de alguien que no sea su autor.

La restricción que más importa es la de reproducción. Parte de este material viene de trabajos confidenciales, y copiarlo fuera de este sitio podría perjudicar a las empresas involucradas.

Trabajo para clientes y material confidencial

Varios proyectos muestran trabajo que hice para empresas como Diligent, Mercado Libre, Conduiit, Edelap, Edge226 y TechUnited:NJ, o dentro de ellas. Ese material se muestra solo para ilustrar mi rol y mi proceso.

Parte de él puede ser confidencial para esas empresas. Donde hizo falta, los nombres, cifras y datos se simplificaron, se ocultaron o se reemplazaron por datos de muestra. Nada de este sitio es una declaración oficial de esas empresas, y no debería compartirse, citarse ni reproducirse fuera del contexto de evaluar mi trabajo.

Marcas

Los nombres de empresas y productos y los logos que aparecen en este sitio pertenecen a sus respectivos dueños. Aparecen acá para identificar los proyectos en los que trabajé y no implican el respaldo de esas empresas.

Privacidad

Este sitio no usa cookies, herramientas de analítica, publicidad ni seguimiento, y no tiene formularios. No recopilo datos personales cuando lo visitás.

Para que las animaciones se vean fluidas, tu navegador guarda una configuración técnica (un nivel de calidad de animación) en su almacenamiento de sesión. No contiene información personal y se borra cuando cerrás la pestaña.

El sitio está alojado en GitHub Pages. GitHub puede registrar información técnica, como tu dirección IP, para operar y proteger el servicio, según se describe en la Declaración de privacidad de GitHub.

Si me escribís, uso tu dirección y tu mensaje solo para responderte. No los comparto ni los vendo, y podés pedirme que los borre cuando quieras.

Pedidos de permiso y de eliminación

Para pedir permiso para usar cualquier contenido, o si representás a una empresa y creés que algo de este sitio debería cambiarse o eliminarse, escribime a daviddhoyos1@gmail.com. Reviso cada pedido y respondo lo antes posible.
